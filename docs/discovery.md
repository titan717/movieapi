# Discovery

Planned discovery endpoints:

- Popular movies
- Popular TV
- Latest movies
- Latest TV
- Upcoming movies
- Upcoming TV
- Airing
- Airing today
- Upcoming airing
- Trending
- Featured
- Genres
- Genre-specific results
- Recommendations
- Home aggregation

The eventual `/api/v1/home` endpoint will aggregate the data Kinoma needs for its homepage to reduce frontend round trips.
